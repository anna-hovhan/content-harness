# Roadmap

## Next
| Item | What it adds |
| --- | --- |
| Carousel posts | a LinkedIn document post: 6 to 10 slides from one idea, using design-assistant's planned `/deck-slide` |
| Repurpose | one piece into the others: an article into 2 or 3 posts, a case study into a post and an article, with the facts kept identical |
| Render helper in design-assistant | a `render` command there (HTML to PNG at a size and scale, after fonts load), so visuals stop needing a one-off script |
| Portfolio content script | from a final `page.md`, draft the `supabase/content/` script in the Portfolio repo, following its `AGENTS.md` (fresh export first) |
| Posting calendar | `content-log.md` plus a plan: which piece goes out which week, and which piece links to which |

## Later
